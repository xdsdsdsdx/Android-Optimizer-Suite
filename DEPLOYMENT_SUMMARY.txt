┌─────────────────────────────────────────────────────────────────────────┐
│ 1️⃣ TERMUX (Recomendado para empezar)                                   │
├─────────────────────────────────────────────────────────────────────────┤
│ ⏱️  Tiempo:        ~5 minutos                                           │
│ 💾 Requisitos:    Solo Termux app + ~500 MB                           │
│ 🎮 Uso:           python3 main.py en terminal                          │
│ ✅ Ventajas:      Instalación muy rápida, fácil debugging              │
│ ⚠️  Limitaciones: Terminal abierta, sin icono en launcher              │
│                                                                         │
│ PASOS:                                                                  │
│ 1. Instala Termux (Google Play / F-Droid)                              │
│ 2. bash termux-install.sh                                              │
│ 3. cd ~/SuiteOptimizacion                                              │
│ 4. python3 main.py                                                     │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 2️⃣ APK COMPILADO (Recomendado para producción)                         │
├─────────────────────────────────────────────────────────────────────────┤
│ ⏱️  Tiempo:        ~30-60 min (primera vez)                            │
│ 💾 Requisitos:    Java JDK 11+ + Android SDK + Python 3.9+            │
│ 🎮 Uso:           Como app nativa en Android                           │
│ ✅ Ventajas:      App profesional, icono en launcher, mejor rendimiento│
│ ⚠️  Limitaciones: Necesita PC para compilar                            │
│                                                                         │
│ PASOS:                                                                  │
│ 1. pip install buildozer cython                                        │
│ 2. cd "ruta_proyecto"                                                  │
│ 3. buildozer android debug                                             │
│ 4. adb install bin/suiteopt-4.2-debug.apk                             │
│ 5. Copia carpeta marcas/ a /storage/emulated/0/SuiteOptimizacion/    │
└─────────────────────────────────────────────────────────────────────────┘

🚀 INICIO RÁPIDO:

📱 EN TERMUX:
   1. Abre Termux
   2. bash termux-install.sh
   3. Copia archivos de marcas/
   4. python3 main.py

💻 EN PC (compilar APK):
   1. Instala requisitos
   2. buildozer android debug
   3. Transfiere APK a teléfono
   4. Instala y ejecuta
